# Project Folder Structure

The recommended project folder structure for the report project is:

```
/workspaces/codespaces-blank/
├── assets/
│   ├── figures/
│   └── README.md
├── results/
├── src/
├── report.md
├── README.md
├── README_PROJECT.md
├── report_docx_structure.md
├── project_structure.md
├── explanation.md
└── requirements.txt
```

## Description
- `assets/` — contains figure files and guidance for images.
- `assets/figures/` — store diagrams and charts used in the report.
- `results/` — stores numerical data and generated plots.
- `src/` — source code for simulation scripts.
- `report.md` — the main academic report in Markdown.
- `README_PROJECT.md` — project guide and export suggestions.
- `report_docx_structure.md` — guidance for DOCX formatting.
- `project_structure.md` — folder structure documentation.
- `explanation.md` — student-friendly explanation of the project.
