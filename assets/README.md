# Assets Guide

This folder contains suggested illustration and figure assets for the academic report.

## Suggested Figures
- `figure1_pes_curve.png` — Potential energy surface for H₂.
- `figure2_simulation_pipeline.png` — Project workflow flowchart.
- `figure3_system_architecture.png` — Block diagram of the hybrid quantum-classical system.
- `figure4_error_mitigation.png` — Diagram showing error correction and mitigation.

## How to Use
- Insert each figure into `report.md` using the placeholder text.
- Replace placeholder images with final graphics during export.

## Tips
- Use clear labels and captions.
- Keep diagrams simple and consistent.
- Use contrasting colors for graph lines and blocks.
